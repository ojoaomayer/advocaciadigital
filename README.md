# Advocacia Digital PRO ⚖️🚀

> Landing page de alta conversão e design system premium para escritórios de advocacia modernos, com estética **Corporate Luxury / Legal Tech**, animações fluidas via **GSAP** e microinterações inspiradas no padrão Apple de design.

---

## 💎 Destaques do Projeto

- **Arquitetura Zero-Config:** Landing page completa e autônoma desenvolvida em HTML5, Tailwind CSS e Vanilla JavaScript.
- **Motion & Animações Fluidas:** Orquestração completa de entrada, scroll interativo e parallax 3D com **GSAP 3** e **ScrollTrigger**.
- **Design System "Corporate Luxury":**
  - Paleta com tons escuros profundos (*Deep Navy & Obsidian Black*).
  - Superfícies com *Glassmorphism* refinado e bordas sutis.
  - Acentos em dourado champagne e azul elétrico.
  - Tipografia sofisticada combinando *Playfair Display* e *Inter*.
- **Microinterações:**
  - Microinterações táteis nos botões e cards com suavização de mola física.
  - Barra de progresso dinâmica em dourado ocupando a lateral da tela.
  - Efeito parallax 3D interativo no mockup do hero.
  - FAQ com accordion animado em tempo real.
- **Deploy Instantâneo & Custo Zero:** Pronto para deploy gratuito na Vercel, Netlify ou GitHub Pages sem dependência de backend ou servidores pagos.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico & Acessibilidade**
- **Tailwind CSS** (via CDN)
- **GSAP (GreenSock)** v3.12.5 + ScrollTrigger
- **Google Fonts** (*Playfair Display* & *Inter*)
- **Ícones Vetoriais SVG** de alta fidelidade

## 🚀 Como Executar Localmente

Você não precisa de build tools pesadas nem de etapas de compilação.

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/ojoaomayer/advocaciadigital.git
   cd advocaciadigital
   ```

2. **Abra diretamente no navegador ou use um servidor local:**
   - Dê um duplo clique no arquivo `index.html`, ou:
   - Utilizando o Node.js:
     ```bash
     npx serve .
     ```
   - Utilizando o Python:
     ```bash
     python -m http.server 3000
     ```

---

## 📦 Deploy em 1 Minuto

- **Vercel:** Conecte o repositório diretamente no painel da Vercel. O deploy é automático e sem configurações adicionais.
- **GitHub Pages:** Ative nas configurações do repositório (*Settings > Pages > Branch: main*).
